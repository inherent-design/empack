# Feature contracts

Capabilities are defined by observable outcomes across commands and consumers.
No export or backend removal may silently discard a supported content obligation.

| Capability | Required behavior |
| --- | --- |
| Initialize and replace | Prepare before mutation; preview, decline and failure preserve original content |
| Import mrpack/CurseForge | Local/remote input, exact bytes, identities, side layers and optionality |
| Provider selection | Search/slug/URL/ID convergence, owned exact pins and stable preference |
| Local/direct content | Verified URL files, JARs, typed ZIPs and unidentified content decisions |
| Content kinds | Mods, resources, shaders, datapacks and interpreted worlds |
| Named files | Multiple provider roles, explicit placements, source/destination separation |
| Author sync | Retain compatible exact selections and required content; materialize explicitly |
| Author update/adopt | Deliberate refresh or verified observed acceptance; no foreign metadata authority |
| Remove | Exact native ownership, alias ambiguity rejection and no directory deletion |
| Requirements | Common/client/server layers, optional groups and conditional fallback |
| Consumers | Modrinth, CurseForge, Prism, server and native empack release |
| Delivery | References or permitted bundled pack bytes independent of update subscription |
| Hosted updates | Signed immutable release plus authenticated monotonic channel selection |
| Instance install/repair | Exact release, choices and verified content; repair does not upgrade |
| Instance update | Three-way reconciliation and one update authority |
| User state | Preserve unowned files, changed configuration, worlds and runtime output |
| Rollback/recovery | Managed rollback and interrupted-publication recovery remain distinct |
| Runtime families | Vanilla, Fabric, Quilt, Forge and NeoForge with supported historical layouts |
| Archives/templates | ZIP, TAR.GZ, 7z where supported; binary copying and syntax-specific rendering |
| Manual content | Exact associations, bounded scans, browser assistance and restart continuation |
| Storage | Verified caches, leases and explicit continuation/recovery retention |
| Batches | Default all-requested; explicit independent author groups with truthful partial outcome |
| Host behavior | Workdir, CLI/env configuration, headless decisions, logs, cancellation and stable exits |
| Launch | Completed installation, runtime compatibility and execution/update coordination |

Packwiz observation, interoperability and installer execution are excluded. Platform
upload automation and a standalone launcher are not implied by compatible exports.
