# v0.9.0-beta portable authoring

The [release target](../development/v0.9.0-beta/README.md) defines the portable
engine, native/browser adapters and SDK acceptance harness. It supersedes this
initial candidate and remains separate from implemented v0.8 contracts.

A product SPA and desktop application are separate phases. The target includes
real desktop and mobile browser acceptance, portable editable-project backups,
Prism ZIP export, tested Modrinth/runtime resolution and restricted-file input.
